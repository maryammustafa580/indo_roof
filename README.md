Indo Roof Cleaning - Quick Summary
What it is: A professional, high-performance web app built for roof cleaning and property services.

Tech Used: Next.js, Tailwind CSS, Framer Motion, Lucide React, and TypeScript.

Key Features: Interactive quote requests (RequestServiceSection) and animated sticky testimonials (IndoRoofTestimonials).

How to Run:

Open terminal in the project folder.

Run npm install (or yarn/pnpm/bun).

Run npm run dev to start the server.

Open http://localhost:3000 in your browser.

Deployment: Easily deploy live by pushing your code to GitHub and importing it into Vercel.
